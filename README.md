# Block2.0
엔트리 비공식 블록입니다.  <br>
Block2.0은 EntSave,StrongBlock, SpecialBlock, ExpressBlock을 참고해서 만들었습니다.<br>
이름이 block2.0인 이유는 엔트리에는 없는 제2의 블럭이라서 그런겁니다!!  <br>
엔트리 리뉴얼 후 최초 작품 보기 창에서 작동 구현!! <br>


작품 만들기나 작품 보는 창에서 콘솔 입력: $.get('https://raw.githack.com/1top10000/Block2.0/main/block.js')  <br>

아마도 오픈소스일걸요...출처는 꼭 남길 필요는 없지만 남겨주세요.
# 설명서
사용법은 F12눌러서 콘솔을 키고 다음을 입력하세요. <br>
`$.get('https://raw.githack.com/1top10000/Block2.0/main/block.js')` <br>
모바일의 경우는 주소창에 다음을 입력하세요. 처음의 x는 같이 복사해서 입력하고 지우세요. <br>
`xjavascript:$.get('https://raw.githack.com/1top10000/Block2.0/main/block.js')` <br>
만약 작품을 최신버전으로 바꾸고싶다면 작품 수정하는곳에 가서 Block2.0을 불러오고 다시 저장해주세요.(작동하는지 확인하고 저장하는 작업은 추천입니다)
