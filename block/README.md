# 버전 방식
[큰버전][중간버전][0,1둘중 하나][작은버전] <br>
큰버전은 2.0, 2.1그런거 <br>
중간버전은 2.1.x에서 x <br>
0으로 끝나는 버전은 버전 올리는 코드가 있음. 1로 끝나는 버전은 버전 올리는 코드가 없음. 꼭 써야하는것은 아니고 필요하면 쓰는방식. <br>
작은버전은 잡다한거 <br>
block.js는 버전 없음 <br>
큰버전과 중간버전이 같으면 호환 가능.
